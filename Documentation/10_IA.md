# Sistema de Inteligencia Artificial

## Vision General

El sistema de IA usa **arboles de comportamiento (Behavior Trees)** para definir la logica de decision de los enemigos. El comportamiento esta separado en dos capas:

- **Rol** (`IDecisionRol`): define la estrategia de combate. Es independiente del tipo de enemigo.
- **Nodos** (`NodoIA`): son los atomos reutilizables (condiciones, acciones) que cada rol compone.

```
EnemigoData.arquetipoIA (enum)
        |
        v
CerebroIA.CrearParaArquetipo()
        |  busca en el registry estatico
        v
IDecisionRol (ej: RolSanador)
        |  compone un arbol de NodoIA y lo evalua cada turno
        v
ResultadoIA { Objetivo, Habilidad }
        |
        v
Enemigos.ObtenerAccionElegida() --> CombateManager
```

## IDecisionRol

**Archivo**: `Assets/Scripts/IA/Roles/IDecisionRol.cs`

Contrato que debe implementar cada archivo de rol.

```csharp
public interface IDecisionRol
{
    ResultadoIA Decidir(
        Enemigos yo,
        List<IEntidadCombate> jugadores,
        List<IEntidadCombate> aliados
    );
}
```

El rol recibe al enemigo que actua, la lista de jugadores (objetivos hostiles) y los aliados (otros enemigos en combate). Retorna un `ResultadoIA` con el objetivo elegido y la habilidad a usar, o `null` si no hay accion valida.

## CerebroIA

**Archivo**: `Assets/Scripts/IA/Core/CerebroIA.cs`

Coordina la toma de decisiones. No contiene logica de combate propia.

### Registry estatico

Mapea `ArquetipoIA` a `IDecisionRol`. Agregar una linea para registrar roles nuevos.

```csharp
private static readonly Dictionary<ArquetipoIA, Func<IDecisionRol>> _registry = new()
{
    { ArquetipoIA.Basico,      () => new RolBasico()      },
    { ArquetipoIA.Guerrero,    () => new RolGuerrero()    },
    { ArquetipoIA.Mago,        () => new RolMago()        },
    { ArquetipoIA.Sanador,     () => new RolSanador()     },
    { ArquetipoIA.Berserk,     () => new RolBerserk()     },
    { ArquetipoIA.Tanque,      () => new RolTanque()      },
    { ArquetipoIA.Controlador, () => new RolControlador() },
    { ArquetipoIA.Soporte,     () => new RolSoporte()     },
};
```

### Uso

```csharp
// Al inicializar desde EnemigoData (Enemigos.InicializarDesdeEnemigoData)
CerebroIA = CerebroIA.CrearParaArquetipo(datos.arquetipoIA);
CerebroIA.Configurar(this);

// Cada turno (Enemigos.ObtenerAccionElegida)
var resultado = CerebroIA.Decidir(jugadores: enemigos, aliados: aliados);
if (resultado?.Habilidad != null)
    return (resultado.Habilidad, resultado.Objetivo);
```

## NodoIA

**Archivo**: `Assets/Scripts/IA/Core/NodoIA.cs`

Clase base abstracta para todos los nodos del arbol. Expone helpers de seleccion de habilidades disponibles en todos los nodos.

```csharp
public abstract class NodoIA
{
    protected Enemigos enemigo;
    protected List<IEntidadCombate> jugadores;
    protected List<IEntidadCombate> aliados;

    public void Configurar(Enemigos enemigo, List<IEntidadCombate> jugadores, List<IEntidadCombate> aliados);
    public abstract EstadoNodo Evaluar();
    public virtual void Resetear() { }

    // Helpers disponibles en todos los nodos:
    protected HabilidadData SeleccionarHabilidadOfensiva(IEntidadCombate objetivo, params CategoriaHabilidad[] prioridades);
    protected HabilidadData SeleccionarHabilidadSoporte(IEntidadCombate objetivo, params CategoriaHabilidad[] prioridades);
    protected IEntidadCombate AliadoMasHerido();
    protected IEntidadCombate AliadoMasFuerte();
}
```

`SeleccionarHabilidadOfensiva` recorre el `GestorHabilidades` del enemigo, filtra por cooldown y `EsViable`, y retorna la primera habilidad que coincide con las categorias indicadas en orden de prioridad. Usa `HabilidadPorDefecto` como fallback.

### ResultadoIA

```csharp
public class ResultadoIA
{
    public IEntidadCombate Objetivo   { get; set; }
    public HabilidadData   Habilidad  { get; set; }
    public TipoAccionIA    TipoAccion { get; set; }

    public enum TipoAccionIA { Atacar, Defender, Huir, Curar, Buff, Debuff, Control, Especial }
}
```

## Nodos de Control

**Archivo**: `Assets/Scripts/IA/Nodos/NodosCompuestos.cs`

### Selector
Prueba hijos en orden. Retorna `Exito` en cuanto uno tiene exito.

### Secuencia
Ejecuta hijos en orden. Retorna `Fallo` en cuanto uno falla.

### SelectorAleatorio
Elige un hijo al azar y lo ejecuta.

## Nodos de Condicion

**Archivo**: `Assets/Scripts/IA/Nodos/NodosCondicionales.cs`

| Clase | Descripcion |
|---|---|
| `CondicionVidaBaja(umbral)` | Verdadero si el enemigo tiene <= umbral% de HP |
| `CondicionJugadorDebil(umbral)` | Verdadero si algun jugador tiene <= umbral% de HP |
| `CondicionAliadoHerido(umbral)` | Verdadero si algun aliado (o el propio enemigo) tiene <= umbral% HP |
| `CondicionAliadosCaidos(n)` | Verdadero si al menos n aliados estan muertos |
| `CondicionProbabilidad(p)` | Verdadero con probabilidad p (0 a 1) |

---

## Nodos de Accion

**Archivo**: `Assets/Scripts/IA/Nodos/NodosAccion.cs`

Todos los nodos de accion usan los helpers de `NodoIA` para seleccionar la habilidad real del `GestorHabilidades`. Nunca hardcodean una habilidad.

| Clase | Objetivo elegido | Categorias priorizadas |
|---|---|---|
| `AccionAtacarDebil` | Jugador con menor % HP | Ataque, Debuff, Control |
| `AccionAtacarTank` | Jugador con mayor HP absoluto | Ataque, Debuff |
| `AccionAtacarAleatorio` | Jugador aleatorio vivo | Ataque, Debuff, Control |
| `AccionControlarObjetivo` | Jugador con menor % HP | Control, Debuff, Ataque |
| `AccionCurarAliado` | Aliado con menor % HP | Curacion |
| `AccionBuffearAliado` | Aliado con mayor HP | Buff, Curacion |
| `AccionCurarse` | El propio enemigo | Curacion, Buff |

Si el nodo no encuentra habilidad disponible (cooldown, sin recursos, no existe), retorna `Fallo` y el arbol prueba la siguiente rama.

## Roles de Combate

**Carpeta**: `Assets/Scripts/IA/Roles/`

Cada rol es un archivo C# que implementa `IDecisionRol`. El rol define las prioridades de combate y es **universal**: un `RolSanador` funciona igual para un goblin sanador, un esqueleto curandero o un elemental de agua.

La raza del enemigo (Goblin, Humano, Elemental) afecta stats y habilidades. El rol afecta la estrategia de combate. Son dos dimensiones ortogonales.

| Archivo | ArquetipoIA | Comportamiento |
|---|---|---|
| `RolBasico.cs` | `Basico` | Se cura si HP critico (60% prob.), ataca aleatorio |
| `RolGuerrero.cs` | `Guerrero` | Se cura solo si HP <= 20%, ataca al mas debil |
| `RolMago.cs` | `Mago` | Se cura a 30%, intenta controlar (45% prob.), ataca al mas debil |
| `RolSanador.cs` | `Sanador` | Cura aliados a 60%, se cura a 40%, buffea (50% prob.), ataca de fallback |
| `RolBerserk.cs` | `Berserk` | Siempre ataca al tanque, sin autopreservacion |
| `RolTanque.cs` | `Tanque` | Se cura a 50%, buffea (35% prob.), ataca al tanque |
| `RolControlador.cs` | `Controlador` | Se cura a 25%, controla (65% prob.), ataca al mas debil |
| `RolSoporte.cs` | `Soporte` | Cura aliados a 70%, se cura a 35%, buffea (50% prob.), ataca de fallback |

`RolSanador` tiene `Decidir()` marcado como `virtual` para permitir herencia sin reescribir todo.

## Agregar un Rol Nuevo

Ejemplo: rol `Invocador` que prioriza habilidades de Utilidad.

### Paso 1 - Agregar el valor al enum

```csharp
// Flags/TipoRecurso.cs
public enum ArquetipoIA
{
    // ... existentes ...
    Invocador,
}
```

### Paso 2 - Crear el archivo del rol

```csharp
// Assets/Scripts/IA/Roles/RolInvocador.cs
namespace IA.Roles
{
    public class RolInvocador : IDecisionRol
    {
        public ResultadoIA Decidir(Enemigos yo, List<IEntidadCombate> jugadores, List<IEntidadCombate> aliados)
        {
            var arbol = new Selector(
                new Secuencia(
                    new CondicionVidaBaja(0.30f),
                    new AccionCurarse()
                ),
                new Secuencia(
                    new CondicionProbabilidad(0.70f),
                    new AccionControlarObjetivo()
                ),
                new AccionAtacarAleatorio()
            );
            arbol.Configurar(yo, jugadores, aliados);
            arbol.Evaluar();
            return ContextoIA.UltimoResultado;
        }
    }
}
```

### Paso 3 - Registrar en CerebroIA

```csharp
// CerebroIA.cs - una sola linea en el registry
{ ArquetipoIA.Invocador, () => new RolInvocador() },
```

### Paso 4 - Asignar en Unity

En el `EnemigoData` del asset -> campo **Arquetipo IA** -> `Invocador`.

## Variante de Rol (herencia)

Si un tipo de enemigo necesita una variacion pequena sobre un rol existente:

```csharp
// RolSanadorAgresivo.cs - cura menos seguido, ataca mas
public class RolSanadorAgresivo : RolSanador
{
    public override ResultadoIA Decidir(Enemigos yo, List<IEntidadCombate> jugadores, List<IEntidadCombate> aliados)
    {
        var arbol = new Selector(
            new Secuencia(new CondicionAliadoHerido(0.35f), new AccionCurarAliado()),
            new Secuencia(new CondicionVidaBaja(0.25f), new AccionCurarse()),
            new AccionAtacarDebil(),
            new AccionAtacarAleatorio()
        );
        arbol.Configurar(yo, jugadores, aliados);
        arbol.Evaluar();
        return ContextoIA.UltimoResultado;
    }
}
```

Registrar como arquetipo nuevo:
```csharp
{ ArquetipoIA.SanadorAgresivo, () => new RolSanadorAgresivo() },
```
